# Security Checklist для Subscription Contract

## ✅ Перед деплоем:

### Критичные проверки:
- [ ] **Сохранена seed фраза** от кошелька-владельца в надёжном месте
- [ ] **Есть тестовые tAI3 токены** для оплаты газа при деплое
- [ ] **Подключена правильная сеть** в MetaMask (Chain ID 8700 для testnet)
- [ ] **Скомпилирован контракт** с версией Solidity 0.8.30+
- [ ] **Проверен адрес владельца** после деплоя (`owner()` должен быть ваш адрес)

### Рекомендуемые улучшения (опционально):

#### Высокий приоритет:
- [ ] Добавить event `OwnershipTransferred` в функцию `transferOwnership()`
  ```solidity
  event OwnershipTransferred(address indexed previousOwner, address indexed newOwner);
  ```

#### Средний приоритет:
- [ ] Изменить `pragma solidity ^0.8.30;` на точную версию `0.8.30;`

#### Низкий приоритет:
- [ ] Убрать модификатор `onlyOwner` (если нужна экономия газа)

## ✅ После деплоя:

### Немедленно:
- [ ] **Скопировать адрес контракта** и сохранить в `.env.local`
- [ ] **Проверить владельца** через explorer (вызвать `owner()`)
- [ ] **Записать адрес контракта** в безопасное место (несколько копий)

### Тестирование:
- [ ] Подключить кошелек к приложению
- [ ] Попробовать подписаться на тестовый план
- [ ] Проверить что MetaMask показывает окно подписания
- [ ] Убедиться что payment приходит на адрес владельца
- [ ] Проверить события в block explorer

### Безопасность:
- [ ] **НЕ ДЕЛИТЬСЯ** seed фразой ни с кем
- [ ] **НЕ ХРАНИТЬ** seed фразу в `.env.local` или других файлах проекта
- [ ] **СДЕЛАТЬ РЕЗЕРВНУЮ КОПИЮ** seed фразы (бумага, металл, сейф)
- [ ] **ПРОВЕРИТЬ** что `.env.local` в `.gitignore`

## 🚨 Что НЕЛЬЗЯ делать:

❌ **НЕ вызывать `transferOwnership()` без необходимости**
❌ **НЕ передавать владение на адрес, который не контролируете**
❌ **НЕ терять seed фразу** (восстановление невозможно!)
❌ **НЕ деплоить на mainnet** без тестирования на testnet
❌ **НЕ загружать `.env.local`** на GitHub

## 📊 Известные проблемы из Aderyn отчёта:

### Высокий приоритет (H-1):
- ✅ **Решено**: Есть проверка `require(success, ...)` при переводе ETH
- ✅ **Решено**: Есть проверка `_newOwner != address(0)` в transferOwnership

### Низкий приоритет (L-1 до L-5):
- ⚠️ **L-1 Centralization**: Нормально для subscription контракта
- ⚠️ **L-2 Pragma**: Можно улучшить (не критично)
- ✅ **L-3 PUSH0**: Не проблема для Autonomys
- ⚠️ **L-4 Modifier**: Можно оптимизировать (не критично)
- ❌ **L-5 Event**: Нет события для `transferOwnership()` (рекомендуется добавить)

## 🔐 Backup Strategy:

1. **Seed фраза владельца**:
   - [ ] Записана на бумаге (хранится в сейфе)
   - [ ] Записана на металле (fireproof backup)
   - [ ] НЕ хранится в цифровом виде

2. **Адрес контракта**:
   - [ ] В `.env.local` (локально)
   - [ ] В документации проекта
   - [ ] В block explorer (bookmark)

3. **Deployment информация**:
   - [ ] Transaction hash деплоя
   - [ ] Block number деплоя
   - [ ] Network (testnet/mainnet)
   - [ ] Дата и время деплоя
