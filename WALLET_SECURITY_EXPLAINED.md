## 💰 Как хранятся деньги?

### Да, деньги временно хранятся В контракте:

```
[Пользователь] --0.01 AI3--> [Smart Contract] --withdrawFunds()--> [Owner]
                              └─ pendingWithdrawal: 0.01 AI3
```

**Почему так сделано:**
1. ✅ **Pull Payment Pattern** - безопаснее чем прямая отправка
2. ✅ **Gas эффективность** - один вывод вместо множества переводов
3. ✅ **Защита от DoS** - owner не может заблокировать подписки

**Цикл жизни денег:**
```
1. Пользователь платит → контракт хранит в pendingWithdrawal
2. Owner вызывает withdrawFunds() → деньги переводятся owner
3. Контракт снова пустой → ждёт новых платежей
```

## 🛡️ Защита от взлома контракта (5 уровней)

### Уровень 1: Защита от Reentrancy атак

**Проблема:** Хакер может повторно войти в функцию во время её выполнения.

**Решение в контракте:**
```solidity
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";

contract SubscriptionSecure is ReentrancyGuard {
    function subscribe(...) external payable nonReentrant {
        // ✅ nonReentrant - блокирует повторный вход
        pendingWithdrawal += msg.value;
    }

    function withdrawFunds() external onlyOwner nonReentrant {
        uint256 amount = pendingWithdrawal;

        // СНАЧАЛА обнуляем (защита!)
        pendingWithdrawal = 0;

        // ПОТОМ переводим
        (bool success, ) = owner().call{value: amount}("");
    }
}
```

**Что это даёт:**
- ❌ Хакер НЕ может вызвать subscribe() дважды одновременно
- ❌ Хакер НЕ может дренажить контракт через reentrancy
- ✅ Только одна транзакция за раз

---

### Уровень 2: Pull Payment Pattern (защита от DoS)

**Проблема:** Если owner - вредоносный контракт, он может блокировать все подписки.

**Старая уязвимая версия (НЕ используем!):**
```solidity
// ❌ ОПАСНО - прямая отправка owner
function subscribe(...) external payable {
    (bool success, ) = owner.call{value: msg.value}("");
    require(success); // ← Если owner.revert() = всё заблокировано!
}
```

**Новая безопасная версия (используем!):**
```solidity
// ✅ БЕЗОПАСНО - сохраняем для вывода позже
function subscribe(...) external payable {
    pendingWithdrawal += msg.value; // Просто увеличиваем счётчик
    // НЕТ внешних вызовов! Не можем быть заблокированы!
}

// Owner сам выводит когда хочет
function withdrawFunds() external onlyOwner {
    uint256 amount = pendingWithdrawal;
    pendingWithdrawal = 0;
    owner.call{value: amount}("");
}
```

**Что это даёт:**
- ✅ Пользователи всегда могут подписаться
- ✅ Даже если owner - вредоносный контракт
- ✅ DoS атака невозможна

### Уровень 3: Emergency Pause (аварийная остановка)

**Проблема:** Обнаружен баг - как остановить контракт?

**Решение:**
```solidity
import "@openzeppelin/contracts/security/Pausable.sol";

contract SubscriptionSecure is Pausable {
    function subscribe(...) external payable whenNotPaused {
        // Если контракт на паузе - эта функция не работает
    }

    // Owner может остановить контракт
    function pause() external onlyOwner {
        _pause(); // ← Все подписки останавливаются
    }

    // И возобновить после fix
    function unpause() external onlyOwner {
        _unpause();
    }
}
```

**Сценарий использования:**
```
1. Обнаружена атака в 10:00
2. Owner вызывает pause() в 10:01
3. Все новые подписки блокируются
4. Хакер НЕ может продолжить атаку
5. Owner исправляет баг
6. Owner вызывает unpause()
7. Контракт снова работает
```

**Что это даёт:**
- ✅ Можно остановить атаку за минуты
- ✅ Средства в безопасности
- ✅ Время на fix и миграцию

### Уровень 4: Ownable2Step (безопасная передача владения)

**Проблема:** Owner опечатался в адресе → контракт потерян навсегда.

**Старый опасный способ:**
```solidity
// ❌ ОПАСНО - опечатка = потеря контракта
transferOwnership(0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb1);
//                                                        ↑
//                                                   опечатка!
// Контракт потерян навсегда
```

**Новый безопасный способ:**
```solidity
import "@openzeppelin/contracts/access/Ownable2Step.sol";

// Шаг 1: Старый owner начинает передачу
transferOwnership(newOwnerAddress);
// Контракт ещё принадлежит старому owner!

// Шаг 2: Новый owner должен ПРИНЯТЬ
newOwner.acceptOwnership();
// Теперь новый owner - владелец

// Если адрес неправильный - новый owner не сможет принять
// Старый owner просто передаст правильному адресу
```

**Что это даёт:**
- ✅ Защита от опечаток
- ✅ Новый owner должен подтвердить
- ✅ Невозможно потерять контроль

### Уровень 5: Rate Limiting (защита от спама)

**Проблема:** Хакер может спамить подписками и тратить gas.

**Решение:**
```solidity
mapping(address => uint256) public lastSubscriptionTime;
uint256 public constant RATE_LIMIT_PERIOD = 1 hours;

function subscribe(...) external payable {
    // Проверка - прошёл ли 1 час с последней подписки
    require(
        block.timestamp >= lastSubscriptionTime[msg.sender] + RATE_LIMIT_PERIOD,
        "Rate limit exceeded"
    );

    lastSubscriptionTime[msg.sender] = block.timestamp;
    // ...
}
```

**Что это даёт:**
- ✅ Максимум 1 подписка в час на адрес
- ✅ Защита от spam атак
- ✅ Нормальные пользователи не затронуты

## 🔬 Технические детали защиты

### Pull Payment Pattern (подробно):

```solidity
// ❌ СТАРЫЙ ОПАСНЫЙ СПОСОБ (Push Payment):
function subscribe(...) external payable {
    // Сразу отправляем owner
    (bool success, ) = owner.call{value: msg.value}("");
    require(success, "Payment failed");

    // ПРОБЛЕМА: Если owner.receive() делает revert()
    // → ВСЕ подписки блокируются
}

// ✅ НОВЫЙ БЕЗОПАСНЫЙ СПОСОБ (Pull Payment):
function subscribe(...) external payable {
    // Просто сохраняем для вывода позже
    pendingWithdrawal += msg.value;

    // Нет внешних вызовов!
    // Невозможно заблокировать подписки
}

function withdrawFunds() external onlyOwner {
    // Owner сам выводит когда хочет
    uint256 amount = pendingWithdrawal;
    pendingWithdrawal = 0; // ← Обнуляем ПЕРЕД отправкой (reentrancy защита)

    (bool success, ) = owner().call{value: amount}("");
    require(success);
}
```

**Преимущества:**
- ✅ Пользователи всегда могут подписаться
- ✅ Owner контролирует когда выводить
- ✅ Если owner.receive() падает → только owner не может вывести
- ✅ Подписки работают независимо от owner

---

### Checks-Effects-Interactions Pattern:

```solidity
function withdrawFunds() external onlyOwner nonReentrant {
    // 1️⃣ CHECKS - Проверки
    uint256 amount = pendingWithdrawal;
    require(amount > 0, "No funds");

    // 2️⃣ EFFECTS - Изменение состояния
    pendingWithdrawal = 0; // ← Обнуляем ПЕРЕД вызовом

    // 3️⃣ INTERACTIONS - Внешние вызовы
    (bool success, ) = owner().call{value: amount}("");
    require(success);
}

// ❌ НЕПРАВИЛЬНЫЙ ПОРЯДОК (уязвимо к reentrancy):
function badWithdraw() external {
    uint256 amount = pendingWithdrawal;

    // СНАЧАЛА внешний вызов
    owner().call{value: amount}("");

    // ПОТОМ обнуляем - СЛИШКОМ ПОЗДНО!
    // Хакер уже вызвал эту функцию повторно
    pendingWithdrawal = 0;
}
```
